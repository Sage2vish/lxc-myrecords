# ChatGPT Context

Repository: `LXC-MyHealthHub`

Current branch:
- `main`

Current integrated work:
- Hostinger-ready Node/Express backend lives in [`lxc-api`](./lxc-databases-apis/lxc-api/)
- Backend versioned routes live under `/v1`
- Swagger UI is available at `/docs`; raw OpenAPI is `/openapi.json`
- `lxc-databases-apis/lxc-apim/` is now an active separate codebase for API management and the grouped catalog/showcase UI
- Local development runs two separate web apps on different ports:
  - `lxc-api` on `http://localhost:3000`
  - `lxc-apim` on `http://localhost:3100`
- APIM catalog URLs stay localhost in `APIM_ENV=local` and only switch to production during the build/deploy flow
- The catalog UI is a grouped API explorer with the group card containing its endpoint rows and a separate full-height API details rail
- `lxc-api` now owns the Doctor REST surface, and `lxc-apim` reads the catalog from `lxc-api/openapi.json` when possible
- MyHealthHub calls the backend weather endpoint first
- Mobile location should pass latitude/longitude; Dubai is the fallback
- Home screen displays city and Celsius temperature below the top glass header,
  outside the header glass, right aligned in ruby pink
- Greeting copy is in its own `greetingGlassSlab`; only top corners are rounded
  from `radii.card`, and the slab extends behind the Family card without moving it

Key rules:
- Work is merged into `main`
- Production WeatherAPI secrets belong in Hostinger env vars
- A temporary mobile dev fallback key path exists only for local/demo continuity
- For iOS work, open the workspace, not the project file
- For Android release work, use the ABI split APK that matches the device
- Do not recreate root-level `publish/`; backend bundles belong in
  `lxc-databases-apis/lxc-api/publish/`

Hostinger deployment:
- Domain shown in Hostinger app deploy flow: `apis.lexvoraconsulting.com`
- Use Express preset and Node 20.x
- Upload the `.tar` bundle generated by `Executable/macos_healthapi_package.sh`
- Set env vars from `lxc-databases-apis/lxc-api/publish/import.env`, replacing placeholder
  secret values inside Hostinger, not in git

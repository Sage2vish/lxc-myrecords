Key rules:
- Work is merged into `main`
- Production WeatherAPI secrets belong in Hostinger env vars
- A temporary mobile dev fallback key path exists only for local/demo continuity
- For iOS work, open the workspace, not the project file
- For Android release work, use the ABI split APK that matches the device
- Do not recreate root-level `publish/`; backend bundles belong in
  `lxc-health-api/publish/`

Hostinger deployment:
- Domain shown in Hostinger app deploy flow: `apis.lexvoraconsulting.com`
- Use Express preset and Node 20.x
- Upload the `.tar` bundle generated by `Executable/macos_healthapi_package.sh`
- Set env vars from `lxc-health-api/publish/import.env`, replacing placeholder
  secret values inside Hostinger, not in git
